# Solux E-Learning app downloads

The Solux E-Learning apps for Windows, macOS, Linux and Android.

**Download them at https://solux-elearning.com/downloads.**

This repository holds releases only. Each one is built, signed and published
automatically by the App release workflow of the Solux E-Learning app; nothing
here is edited by hand. Installed apps update themselves from `latest.json`
in the newest release.
